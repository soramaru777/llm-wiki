# 秘密情報の検出パターン（単一定義）
#
# githooks/pre-commit（Git クライアント側）と svnhooks/pre-commit（SVN サーバ側）が
# このファイルを共有する。**二重管理しないこと。** 片方だけ更新されると必ず腐る。
#
# 書式:
#   - 1行1パターン。拡張正規表現（ERE）、大文字小文字は区別しない
#   - `#` で始まる行と空行は無視
#   - `!` で始まる行は「除外」。検出行がこれに一致したら誤検知として通す
#
# 探索されるファイル:
#   1. スクリプトと同じディレクトリの secret-patterns.txt（配置後）
#   2. スクリプトの親の lib/secret-patterns.txt（このリポジトリ内）

# --- 検出パターン -------------------------------------------------------

# Anthropic
sk-ant-[A-Za-z0-9_-]{20,}

# OpenAI 系
sk-[A-Za-z0-9]{32,}

# GitHub（personal access token / OAuth / refresh / server-to-server）
(gh[pousr]|github_pat)_[A-Za-z0-9_]{20,}

# AWS アクセスキー ID
AKIA[0-9A-Z]{16}

# Fly.io デプロイトークン
FlyV1 [A-Za-z0-9_+/=-]{20,}

# Slack
xox[baprs]-[A-Za-z0-9-]{10,}

# Google API キー
AIza[A-Za-z0-9_-]{35}

# 秘密鍵
-----BEGIN [A-Z ]*PRIVATE KEY-----

# 値が実際に入っている代入。KEY= のような空代入やプレースホルダは下の除外で落ちる
(API_KEY|APIKEY|SECRET|TOKEN|PASSWORD|PASSWD|CREDENTIAL)[A-Z_]*[=:][[:space:]]*["']?[A-Za-z0-9_/+.=-]{16,}

# --- 除外（誤検知の防止）-----------------------------------------------
# ドキュメントやテンプレートで使う書き方を通す

!\$\{
!\$[A-Z_]+
!\*\*\*

!placeholder
!redacted
!dummy
!sample
